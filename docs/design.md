# FlashDesk 设计约定

面向 Windows 上需要跨芯片烧录的开发者，主界面是一张操作台。左侧选择芯片，中间按连接、固件、执行的顺序操作，下方持续显示工具原始输出。

- 色板：工作区 #F0F4F8，纸面 #FFFFFF，文字 #172D43，操作蓝 #175CD3，边线 #CFD9E4，提示琥珀 #946200。
- 字体：中文 Microsoft YaHei UI，日志与命令 Cascadia Mono / Consolas。
- 布局：左侧 220px 芯片目录，右侧自适应表单及日志；全部左对齐。有限圆角，无渐变和装饰性数据卡。
- 特征：芯片封装轮廓作为品牌标记，明确分开的虚拟演练与真实烧录，先预览命令再执行，显示固件指纹和后端工具的真实输出。

审视：普通仪表盘常将所有参数做成等大的卡片，隐藏任务顺序。本项目改成一张纵向工作单，连接参数与固件信息用分隔线分组，主要空间留给日志；烧录状态必须包含「虚拟」或「真实」字样。

v0.2 配置扩展：沿用原色板、字体与工作台布局。工程方案置于标题下方；参数区分为「连接与固件」及以当前芯片命名的配置页，使用可滚动表单容纳不同数量的字段，执行按钮固定在表单外。审视后放弃把所有芯片选项堆到一页的方案；选项按后端能力和连接接口显示，保留日志空间。

v0.2.1：配置页按已有芯片领域分组，分组标题右侧提供「重置此分区」，页首提供「重置本页」。复用既有蓝灰色板和字体，不增加装饰。公开 README 使用居中标题、真实版本 / 平台徽章和应用截图；文档详细内容移到使用说明中，保持首页可扫描。公开截图由实际控件渲染，清除本机工程名称、日志和路径。

v0.3.0：芯片与工具组合增至 32 个。侧栏增加全部 / 51 / STM32 / AVR / ESP 分类，与搜索组合使用，保留已有配置顺序和 ID。型号名标明不同下载工具与连接方式；选项由协议与器件决定，避免为 AT89S 显示 AVR 熔丝。工具设置改为可滚动列表以容纳 7 类工具。
