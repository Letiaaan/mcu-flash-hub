# 51 / 8051：先看完整料号，再选下载方式

左侧分类选择「51 / 8051」，可查看本版 14 个配置。型号中的 C、S、RC、RD+、封装后缀不能省略。以下是选型与接入说明，软件与虚拟流程已测试；实物接线、电压与烧录结果尚待验证。

| 芯片 | 工具 | 硬件方式 | 操作要点 |
|---|---|---|---|
| STC89 / STC90 | 内置 stcgal | UART 冷启动下载 | 点击开始后重新给芯片上电；6T / 12T、ALE、XRAM 等选项默认保持 |
| STC12C5A60S2 | 内置 stcgal，stc12 协议 | UART 冷启动下载 | 使用专属选项；时钟来源、复位、看门狗、EEPROM 擦除默认保持 |
| STC15F104E | 内置 stcgal，stc15a 协议 | UART 冷启动下载 | 与其他 STC15 的协议、配置不同，不能混选 |
| STC15F2K60S2 / STC15W4K32S4 | 内置 stcgal，stc15 协议 | UART 冷启动下载 | RC 校准频率 0 表示不指定；本版不开放动态 EEPROM 重分区 |
| STC8A8K64S4A12 | 内置 stcgal，stc8 协议 | UART 冷启动下载 | 按上游模型限制代码区为 65024 字节 |

| AT89C51 / AT89C52 | 外部 MiniPro CLI | 并行编程器与芯片座 | 选择 DIP40 / PLCC44 / TQFP44；先核对工具数据库、器件电压与转接座 |

## STC 教学板

使用合适电平的 USB-TTL，TX 与 RX 交叉并共地，供电按芯片和开发板手册。DTR / RTS 不能直接代替芯片电源；只有外部电源控制电路正确时才启用自动电源复位。不要把 RS-232 电平接口直接接到 TTL 引脚。

先选完整型号，再载入 Keil 生成的 HEX 或 SDCC 生成的 IHX，也可使用 BIN。stcgal 区分扩展名大小写，Intel HEX 扩展名须为小写 `.hex` / `.ihx` / `.ihex`。程序代码与单独 EEPROM 文件均要求从地址 0 开始；软件会检查容量和指纹。

保持所有硬件项原值完成第一次验证，再按工程需要更改时钟、看门狗等选项。配置页「重置」恢复的是界面默认值：下次不主动修改芯片设置，不会撤销此前已写入的硬件设置。芯片实际型号需人工核对 stcgal 日志，本版没有强制匹配料号。

stcgal 成功表示工具协议流程完成，本版未提供 STC 独立 Flash 读回。最后还需检查芯片的实际运行、串口输出或 LED 等可观测行为。

## AT89S 与 AT89C

AT89S51/S52 可以经 ISP 编程，但不能直接使用 STC 冷启动串口下载。本版提供兼容 8051 固件的 USBasp 和串口 AVRISP 两种配置；所选工具、驱动及固件必须实际支持目标器件。默认 ISP 周期 32 μs，可按目标时钟调整。它们没有 AVR 的低 / 高 / 扩展熔丝，界面不提供这些字段，也不提供 Arduino Bootloader 或独立 EEPROM。

AT89C51/C52 需要受支持的并行编程器。MiniPro 是开源 CLI，与厂商图形程序不是同一个入口；需自行准备可运行于 Windows 的构建及数据库，本应用不自动安装，也不通过 WSL 调用。连接前用工具的设备列表 / 详情确认精确型号与封装。默认启用写后校验和 ID 检查；应用不提供强制忽略 ID、电压修改、锁定位或编程器固件升级。编程可能擦除整颗芯片。

## 现阶段边界

本版没有自动控制 STC-ISP、FlyMCU、Keil 或厂商 MiniPro GUI。界面中的支持仅对应表内 CLI 适配。虚拟模式验证参数、模型写入、错误处理和报告，不模拟电气时序、下载握手或程序执行。软件验收记录见 [acceptance.md](acceptance.md)。
